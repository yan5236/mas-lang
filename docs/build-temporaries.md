# 编译与运行临时目录

编译器为每次链接原子创建独占目录，名称包含用途前缀、进程 PID 和进程内递增计数器。遇到已有同名目录会重试，不会复用旧目录；不依赖时钟精度。

`TemporaryDirectory` 持有目录生命周期。`BuildWorkspace` 持有该守卫，成功、链接失败和错误返回时清理 bootstrap 源码、对象文件及原生中间文件。显式指定的最终构建产物留在用户输出路径。

编译器 `run` 与 fama 内嵌 `run` 将 EXE/PDB 放在独占临时目录，持有守卫直到子进程结束，然后清理。fama 外部模式由所配置编译器负责，旧版本外部编译器需要更新后才能获得相同清理行为。

清理失败会报告目录与系统错误。操作系统强制终止编译器时不会执行析构，因此不承诺强制终止后的自动清理。

验证见 `tests/temp_workspace.rs`：64 个同时持有的目录、六次真实并行构建、运行成功、运行错误与链接错误；检查隔离临时根是否为空。
