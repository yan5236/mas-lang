# 关键字列表

以下是 mas-lang 的保留标识符，不能用作变量名或函数名：

| 名称 | 分类 | 说明 |
|------|------|------|
| `and` | 关键字 | 逻辑与 |
| `as` | 关键字 | 导入别名 |
| `bool` | 内置函数 | 转换为布尔值 |
| `break` | 关键字 | 退出循环 |
| `const` | 关键字 | 声明常量 |
| `continue` | 关键字 | 继续下一轮循环 |
| `elif` | 关键字 | 否则如果 |
| `else` | 关键字 | 否则 |
| `export` | 关键字 | 重新导出（与 import 配合） |
| `extern` | 关键字 | 声明外部 C 函数 |
| `float` | 内置函数 | 转换为浮点数 |
| `for` | 关键字 | for 循环 |
| `func` | 关键字 | 定义函数 |
| `if` | 关键字 | 条件判断 |
| `import` | 关键字 | 导入模块 |
| `in` | 关键字 | 遍历集合 |
| `int` | 内置函数 | 转换为整数 |
| `len` | 内置函数 | 获取容器长度 |
| `not` | 关键字 | 逻辑非 |
| `or` | 关键字 | 逻辑或 |
| `print` | 内置函数 | 打印输出 |
| `pub` | 关键字 | 公开可见性 |
| `return` | 关键字 | 返回值 |
| `string` | 内置函数 | 转换为字符串 |
| `try_bool` | 内置函数 | 安全转换为布尔值 |
| `try_float` | 内置函数 | 安全转换为浮点数 |
| `try_int` | 内置函数 | 安全转换为整数 |
| `var` | 关键字 | 声明变量 |
| `while` | 关键字 | while 循环 |

此外，`true` 和 `false` 是布尔字面量，同样不能用作标识符。
