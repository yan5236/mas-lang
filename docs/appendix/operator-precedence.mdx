# 运算符优先级

从低到高排列：

| 优先级 | 运算符 | 说明 |
|--------|--------|------|
| 1（最低） | `or` | 逻辑或 |
| 2 | `and` | 逻辑与 |
| 3 | `==` `!=` | 等于 / 不等于 |
| 4 | `<` `<=` `>` `>=` | 比较 |
| 5 | `+` `-` | 加法、减法、字符串拼接 |
| 6 | `*` `/` `%` `%/%` | 乘法、除法、取模、整数除法 |
| 7 | `-` `not` | 一元负号、逻辑非 |
| 8（最高） | `()` `[]` `.` `[:]` | 函数调用、索引、成员访问、切片 |

所有二元运算符都是左结合的。使用括号 `()` 可以改变运算顺序：

```mas-lang
var result = (2 + 3) * 4   // 20
```
