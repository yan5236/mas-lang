# time — 时间标准库

`time` 模块提供墙钟时间获取与单调时钟计时功能，包含 7 个公开函数。

## 导入

```mas-lang
import time { now_unix, now_iso8601, monotonic_millis, sleep }
```

按需导入所需函数。`time` 为标准库模块，无需额外依赖。

## 函数一览

| 函数 | 返回类型 | 说明 |
|------|---------|------|
| `now_unix()` | `int` | 当前 Unix 时间戳（秒） |
| `now_unix_millis()` | `int` | 当前 Unix 时间戳（毫秒） |
| `now_iso8601()` | `string` | ISO 8601 / RFC 3339 格式 UTC 字符串 |
| `now_rfc2822()` | `string` | RFC 2822 格式 UTC 字符串 |
| `now_rfc7231()` | `string` | HTTP-date 格式 UTC 字符串 |
| `monotonic_millis()` | `int` | 单调时钟毫秒计数 |
| `sleep(ms)` | 无 | 线程休眠指定毫秒数 |

## 注意事项

- 所有墙钟时间函数均返回 **UTC 时间**，不提供本地时区转换
- `monotonic_millis` 的起点是系统启动时间，不可与墙钟时间混用
- `sleep` 传入负数会导致运行时错误
