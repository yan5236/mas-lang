# 介绍

mas-lang 是一门静态类型、编译型编程语言。它采用类 Python 的缩进语法，代码清晰简洁，同时通过 LLVM 编译为高效的原生二进制文件。

## Hello World

```mas-lang
print("Hello, mas-lang!")
```

编译并运行：

```
fama build
./build/output
```

## 语言特性

- **静态类型**：所有变量和表达式的类型在编译时确定，提前发现类型错误
- **类型推断**：变量声明时可省略类型标注，编译器自动推断
- **Python 式语法**：缩进定义代码块，无需括号和分号
- **原生编译**：基于 LLVM 编译为机器码，直接运行无需运行时环境
- **丰富的数据结构**：list、map、array 等容器类型
- **模块系统**：支持文件级模块组织、导入导出

## 快速上手

创建一个新项目：

```
fama new hello
cd hello
fama run
```

`src/main.ms` 是程序入口，在此编写代码后执行 `fama run` 即可查看结果。
