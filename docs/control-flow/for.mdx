# for 循环

## 范围循环

使用 `for i in start..end` 遍历整数范围（左闭右开）：

```mas-lang
for i in 0..5:
    print(i)
// 输出 0 1 2 3 4
```

## 遍历列表

```mas-lang
var items = ["苹果", "香蕉", "橙子"]
for item in items:
    print(item)
```

## 遍历字典

遍历字典的键和值：

```mas-lang
var user = {"name": "张三", "age": 18}
for key, value in user:
    print("${key}: ${value}")
```

只遍历键：

```mas-lang
for key in user:
    print(key)
```

## break 和 continue

`break` 和 `continue` 同样适用于 for 循环：

```mas-lang
for i in 0..10:
    if i % 2 == 0:
        continue
    print(i)
// 输出奇数：1 3 5 7 9
```
