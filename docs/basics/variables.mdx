# 变量与常量

## var — 可变变量

使用 `var` 声明可变变量，可重新赋值：

```mas-lang
var x = 42
x = 100           // 重新赋值

var name: string = "mas-lang"
name = "新的值"   // 重新赋值
```

## const — 不可变常量

使用 `const` 声明常量，初始化后不可变更：

```mas-lang
const PI = 3.14159
const MAX_SIZE: int = 100

// PI = 3.14      // 错误：常量不可重新赋值
```

常量声明时必须提供初始值。

## 复合赋值运算符

支持以下复合赋值操作：

```mas-lang
var a = 10
a += 5    // a = 15
a -= 3    // a = 12
a *= 2    // a = 24
a /= 4    // a = 6
a %= 3    // a = 0
```

## 索引赋值

对列表和字典的元素进行赋值：

```mas-lang
var list = [1, 2, 3]
list[0] = 10       // list 变为 [10, 2, 3]

var map = {"name": "张三"}
map["name"] = "李四"
```

索引赋值不支持复合运算符（如 `list[0] += 1` 是错误的）。
