# 注释与缩进

## 注释

使用 `//` 表示单行注释，从 `//` 到行尾的内容被编译器忽略：

```mas-lang
// 这是注释
var x = 42  // 行尾注释
```

注释可以出现在任何位置。不支持多行注释（`/* */`）。

## 缩进规则

mas-lang 使用缩进定义代码块，类似 Python。

- **每级缩进为 4 个空格**，不支持 Tab
- 冒号 `:` 后开始新的缩进块
- 同一代码块内的语句必须保持相同缩进

```mas-lang
if x > 0:
    print("正数")    // 缩进 4 空格
    x = x - 1        // 同一块，同为 4 空格
else:
    print("非正数")  // 新块，4 空格
```

- 空行不改变缩进状态
- 纯注释行（仅含空格和 `//`）不影响缩进
- 块内不能为空
