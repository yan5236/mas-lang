# 运算符优先级

从低到高排列：

| 优先级 | 运算符 | 说明 |
|--------|--------|------|
| 1（最低） | `or` | 逻辑或 |
| 2 | `and` | 逻辑与 |
| 3 | `==` `!=` | 等于 / 不等于 |
| 4 | `<` `<=` `>` `>=` | 比较 |
| 5 | `+` `-` | 加法、减法、字符串拼接 |
| 6 | `*` `/` `%` `%/%` | 乘法、除法、取模、整数除法 |
| 7 | `-` `not` | 一元负号、逻辑非 |
| 8（最高） | `()` `[]` `.` `[:]` | 函数调用、索引、成员访问、切片 |

所有二元运算符都是左结合的，因此不能写链式比较：`1 < 2 < 3` 会解析成 `(1 < 2) < 3` 并报类型错误，应写成 `1 < 2 and 2 < 3`。

`not` 与一元负号同级，且高于比较运算：`not a == b` 解析为 `(not a) == b`。要表达“a 不等于 b”，请写 `not (a == b)`。

`..` 不是普通表达式运算符，只用于 `for` 范围，例如 `for i in 0..len(items)`。它的两个端点各是一个完整表达式，所以 `0..2 + 1` 等价于 `0..(2 + 1)`。

使用括号 `()` 可以改变运算顺序：

```mas-lang
var result = (2 + 3) * 4   // 20
```
