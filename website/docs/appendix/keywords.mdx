# 关键字与内置名称

## 关键字（保留字）

以下标识符是语言关键字，不能用作变量名、函数名或结构体名：

| 名称 | 分类 | 说明 |
|------|------|------|
| `and` | 关键字 | 逻辑与 |
| `as` | 关键字 | 导入别名 |
| `break` | 关键字 | 退出循环 |
| `const` | 关键字 | 声明常量 |
| `continue` | 关键字 | 继续下一轮循环 |
| `elif` | 关键字 | 否则如果 |
| `else` | 关键字 | 否则 |
| `export` | 关键字 | 重新导出（与 import 配合） |
| `extern` | 关键字 | 声明外部 C 函数 |
| `false` | 字面量 | 布尔假 |
| `for` | 关键字 | for 循环 |
| `func` | 关键字 | 定义函数 |
| `if` | 关键字 | 条件判断 |
| `import` | 关键字 | 导入模块 |
| `in` | 关键字 | 遍历集合 |
| `not` | 关键字 | 逻辑非 |
| `null` | 字面量 | 可空类型的空值 |
| `or` | 关键字 | 逻辑或 |
| `pub` | 关键字 | 公开可见性 |
| `return` | 关键字 | 返回值 |
| `struct` | 关键字 | 使用缩进定义结构体 |
| `true` | 字面量 | 布尔真 |
| `var` | 关键字 | 声明变量 |
| `while` | 关键字 | while 循环 |

## 内置函数（不是关键字）

以下名称是全局可用的内置函数。它们**可以**用作变量名，但不能用来定义同名函数或结构体：

| 名称 | 说明 |
|------|------|
| `print` | 打印输出（只接受基础类型） |
| `len` | 获取字符串、列表、字典或数组长度 |
| `int` `float` `string` `bool` | 基础类型转换 |
| `try_int` `try_float` `try_bool` | 安全转换，返回带 `ok`/`value` 的结果 |

例如 `var print = 1` 是合法的；但 `func print(...)`、`struct print:` 会报“不能覆盖内建名称”。

`int`、`float`、`string`、`bool`、`list`、`map`、`array` 同时是类型名，但它们本身不是关键字：`var int = 1`、`var list = 1` 可以编译。`main` 不是关键字，但不能给结构体起名 `main`，可执行程序也必须定义无参数 `func main()`。
