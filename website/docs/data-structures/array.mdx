# 固定数组

## 类型

`array<T,N>` 是固定长度的数组，长度 N 在编译期确定：

```mas-lang
var arr: array<int, 3>
```

## 初始化

```mas-lang
var arr = array<int, 3>(1, 2, 3)
```

## 索引访问

```mas-lang
arr[0]   // 1
arr[2]   // 3
```

有效下标范围为 `0 <= index < N`。负数和超出范围的下标会报告带源码位置的运行时错误并以状态码 1 退出，不会返回任意内存值。

## 与列表的区别

| 特性 | list | array |
|------|------|-------|
| 长度 | 动态增长 | 编译期固定 |
| 方法 | 支持 append、remove、pop 等 | 无增删方法 |
| 存储 | 堆分配 | 栈分配 |
| 遍历 | 支持 | 支持 |

```mas-lang
var arr = array<int, 3>(1, 2, 3)
len(arr)          // 3

for item in arr:
    print(item)
```

## 结构体与可空元素

```mas-lang
struct Person:
    name: string

var people = array<Person?,2>(Person("Alice"), null)
people[1] = Person("Bob")
print(people[1].value.name)
```

数组也支持列表、字典和嵌套数组元素，并追踪其中的托管引用。数组赋值复制数组槽位；结构体、列表和字典元素仍共享对象引用。嵌套下标赋值写回原数组位置。
