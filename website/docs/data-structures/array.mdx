# 固定数组

## 类型

`array<T,N>` 是固定长度的数组，长度 N 在编译期确定：

```mas-lang
var arr: array<int, 3>
```

省略初始化时所有槽位为零值（数值 `0`、`bool` 为 `false`、引用和字符串为空）。

## 初始化

```mas-lang
var arr = array<int, 3>(1, 2, 3)
```

初始化必须提供恰好 N 个元素，且元素类型与声明一致。

## 索引访问

```mas-lang
arr[0]   // 1
arr[2]   // 3
```

有效下标范围为 `0 <= index < N`。负数和超出范围的下标（读取或写入）会报告带源码位置的运行时错误并以状态码 1 退出，不会返回任意内存值。

## 可恢复的下标读写

需要自己处理失败时用 `try_get`/`try_set`：失败不会终止程序，也不会改动元素。

```mas-lang
func main():
    var arr = array<int, 3>(10, 20, 30)

    var hit = arr.try_get(1)      // ok = true，value = 20
    var miss = arr.try_get(3)     // ok = false
    print(arr.try_get(-1).ok)     // false

    print(arr.try_set(1, 99))     // true，arr 变为 (10, 99, 30)
    print(arr.try_set(3, 99))     // false，arr 保持 (10, 99, 30)
    print(arr[1])                 // 99
```

| 方法 | 返回 | 说明 |
|------|------|------|
| `try_get(i)` | `try_result<T>` | `0 <= i < N` 才成功，否则 `ok = false` |
| `try_set(i, v)` | `bool` | 下标合法才写入；失败返回 `false` 且保持原值 |

和列表一样，先用 `.ok` 判断，成功后再读 `.value`。失败时标量和字符串载荷可以安全读取；结构体、列表、字典以及含托管元素的数组没有安全占位值，直接读取 `.value` 会报告带源码位置的语言错误并以状态码 1 退出。`try_set` 只能作用于有固定存储位置的数组（变量或结构体字段里的数组）。数组元素本身是一份拷贝，例如 `grid[0]`、函数返回的数组都没有可写地址，对它们调用 `try_set` 会在语义分析阶段被拒绝；这种场景改用下标赋值 `grid[0][1] = v`，越界时仍按严格下标写入的语义退出。

## 与列表的区别

| 特性 | list | array |
|------|------|-------|
| 长度 | 动态增长 | 编译期固定 |
| 方法 | 支持 append、remove、pop 等 | 无增删方法 |
| 存储 | 堆分配，句柄共享 | 内联值，局部数组位于栈帧 |
| 遍历 | 支持 for-in | 不支持 for-in，用下标范围循环 |
| 切片 | 支持 | 不支持 |

```mas-lang
var arr = array<int, 3>(1, 2, 3)
len(arr)          // 3

for i in 0..len(arr):
    print(arr[i])
```

`0..len(arr)` 是左闭右开区间，刚好覆盖所有下标。也可以写成 `for i in 0..3:`。

## 结构体与可空元素

```mas-lang
struct Person:
    name: string

var people = array<Person?,2>(Person("Alice"), null)
func main():
    people[1] = Person("Bob")
    print(people[1].value.name)
```

数组元素可以是基础类型、结构体、可空值、列表、字典或嵌套数组，例如 `array<list<int>,2>`、`array<array<int,2>,2>`。初始化嵌套数组时要显式写出内层数组：

```mas-lang
var grid = array<array<int, 2>, 2>(array<int, 2>(1, 2), array<int, 2>(3, 4))
```

数组赋值复制数组槽位；结构体、列表和字典元素仍共享对象引用。嵌套下标赋值会写回原数组位置：

```mas-lang
var grid = array<array<int, 2>, 2>(array<int, 2>(1, 2), array<int, 2>(3, 4))
grid[0][1] = 9
print(grid[0][1]) // 9
```

固定数组是内联值，不能直接放进列表或字典的值；需要动态容器时改用列表。
