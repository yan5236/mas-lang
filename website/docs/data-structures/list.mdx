# 列表

## 类型与字面量

`list<T>` 是动态数组，存储同类型的基础值、结构体、可空值、列表或字典：

```mas-lang
var list = [1, 2, 3, 4]           // list<int>
var names: list<string> = ["a", "b"]
var empty: list<int> = []
```

空列表 `[]` 没有可推断的元素类型，必须放在显式 `list<T>` 标注或参数类型上下文中。列表也支持嵌套，例如 `var rows: list<list<int>> = [[], [1, 2]]`；动态列表里不能放固定数组（`list<array<int,3>>` 会编译失败）。

## 索引访问

索引从 0 开始：

```mas-lang
var list = [10, 20, 30]
list[0]   // 10
list[2]   // 30
```

负数和超出范围的下标会报告运行时错误并以状态码 1 退出。

## 切片

```mas-lang
var list = [1, 2, 3, 4, 5]
list[1:3]   // [2, 3]
list[:3]    // [1, 2, 3]
list[2:]    // [3, 4, 5]
```

切片范围左闭右开；负数或越界范围会报告运行时错误，不支持步长。切片会复制元素槽位（得到新的列表），但结构体、列表和字典元素仍共享原对象引用。

## 列表方法

```mas-lang
var list = [1, 2, 3]

list.append(4)              // [1, 2, 3, 4]
list.remove(2)              // 删除第一个 2，list 变为 [1, 3, 4]
list.pop()                  // 返回 4，list 变为 [1, 3]
list.pop(0)                 // 返回 1，list 变为 [3]
list.sort()                 // 原地排序
list.reverse()              // 原地反转
list.index(3)               // 返回元素下标
list.contains(3)            // true
len(list)                   // 长度
```

| 方法 | 返回 | 说明 |
|------|------|------|
| `append(v)` | 无 | 追加到末尾 |
| `remove(v)` | 无 | 删除第一个等于 `v` 的元素；不存在时报运行时错误 |
| `pop()` | 元素类型 | 删除并返回最后一个元素；空列表报运行时错误 |
| `pop(i)` | 元素类型 | 删除并返回下标 `i` 的元素；越界报运行时错误 |
| `sort()` | 无 | 原地升序排序，见下文规则 |
| `reverse()` | 无 | 原地反转，不要求元素可比较 |
| `index(v)` | `int` | 返回第一个匹配元素的下标；不存在时报运行时错误 |
| `contains(v)` | `bool` | 是否包含元素 |
| `len(list)` | `int` | 元素个数 |

`sort()` 只支持元素全部为 `int`、`float`、`bool` 或 `string` 的列表：`bool` 按 `false < true`，`string` 按 UTF-8 字节序（区分大小写），`float` 按数值升序（`-0.0` 与 `0.0` 相等）。浮点列表含 NaN 时顺序仍然是确定的：所有 NaN 排在全部数值之后，NaN 之间按位模式升序。结构体列表和可空元素列表不支持 `sort()`，但支持 `reverse()`。

## 可恢复访问与修改

下标读写、`index`、`remove`、`pop` 和切片失败时会报错并以状态码 1 退出。需要自己处理失败时用下面这组 `try_*` 方法：失败不会终止程序，也不会改动列表。

```mas-lang
func main():
    var nums = [10, 20, 30]

    var hit = nums.try_get(1)        // ok = true，value = 20
    var miss = nums.try_get(5)       // ok = false
    print(hit.value)                 // 20

    print(nums.try_set(1, 99))       // true，nums 变为 [10, 99, 30]
    print(nums.try_set(5, 99))       // false，nums 保持 [10, 99, 30]

    print(nums.try_index(99).ok)     // true
    print(nums.try_index(7).ok)      // false

    print(nums.try_remove(7))        // false，nums 保持 [10, 99, 30]
    print(nums.try_remove(99))       // true，nums 变为 [10, 30]

    var empty: list<int> = []
    print(empty.try_pop().ok)        // false，不删除元素
    print(nums.try_pop(9).ok)        // false，nums 保持 [10, 30]
    print(nums.try_pop().value)      // 30，nums 变为 [10]

    var part = nums.try_slice(0, 1)  // ok = true，value 为 [10]
    print(nums.try_slice(2, 1).ok)   // false，倒序范围不合法
```

| 方法 | 返回 | 说明 |
|------|------|------|
| `try_get(i)` | `try_result<T>` | `0 <= i < len` 才成功，否则 `ok = false` |
| `try_set(i, v)` | `bool` | 下标合法才写入；失败返回 `false` 且保持原值 |
| `try_pop()` | `try_result<T>` | 空列表返回 `ok = false`，不删除元素 |
| `try_pop(i)` | `try_result<T>` | 越界返回 `ok = false`，不删除元素 |
| `try_index(v)` | `try_result<int>` | 未命中返回 `ok = false`，不报错 |
| `try_remove(v)` | `bool` | 未命中返回 `false`；命中删除第一个匹配元素 |
| `try_slice(a, b)` | `try_result<list<T>>` | `0 <= a <= b <= len` 才成功，返回新列表 |

结果先用 `.ok` 判断是否成功，成功后再读 `.value`。失败时 `.value` 的占位值分两类：标量和字符串可以安全读取（`0`、`0.0`、`false`、有效空串）；结构体、列表、字典以及含托管元素的数组没有安全的占位值，直接读取 `.value` 会报告带源码位置的语言错误并以状态码 1 退出。所有 `try_*` 失败都保持列表的长度、元素和引用关系不变，后面的代码继续执行。`try_slice` 和切片一样复制元素槽位，结构体、列表和字典元素仍共享原对象引用。`try_pop(i)` 会先求值下标实参，再按接收者当前长度判断：实参缩容后旧下标被拒绝，扩容后新增元素可以弹出。

元素本身可为 `null` 时，`.ok` 区分两种情况：`try_get` 得到 `ok = true` 且 `.value == null` 表示该位置存在一个 `null` 元素，`ok = false` 表示下标无效。`try_index`、`try_remove` 也能匹配 `null` 元素。

## 遍历

```mas-lang
var items = ["苹果", "香蕉", "橙子"]
for item in items:
    print(item)
```

遍历列表只能声明一个循环变量；第二个变量会报错。只要下标时用范围循环：

```mas-lang
for i in 0..len(items):
    print(items[i])
```

## 结构体元素

可以用 `list<Person>` 存储已经定义的 `Person` 结构体，也可以用 `[Person(...)]` 推断类型。支持追加、下标读写、遍历、切片、弹出和反转；元素共享对象引用。`contains/index/remove` 按对象引用匹配，`sort()` 不支持结构体元素。完整示例见[结构体列表](./struct#用列表管理多个结构体)。

可空基础元素的 `contains/index/remove` 按内容匹配（两个 `null` 相同），结构体和容器按对象引用匹配。`sort()` 仅支持非可空基础元素。固定数组是内联值，不能直接作为动态列表元素；这类场景使用嵌套列表。
