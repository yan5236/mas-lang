# 字典

## 类型与字面量

`map<K,V>` 是键值对字典：

```mas-lang
var user = {"name": "张三", "city": "上海"}   // map<string,string>
var scores: map<string, int> = {}
```

多行书写：

```mas-lang
var config = {
    "host": "localhost",
    "port": "8080",
    "debug": "true",
}
```

## 键访问

```mas-lang
var user = {"name": "张三", "city": "上海"}
user["name"]   // "张三"
```

## 添加和更新

```mas-lang
user["email"] = "zhang@example.com"   // 添加新键
user["city"] = "北京"                       // 更新已有键
```

## 字典方法

```mas-lang
var map = {"a": 1, "b": 2, "c": 3}

map.remove("b")           // 删除键 "b"
map.contains("a")         // true
map.keys()                // ["a", "c"]（键的列表）
map.values()              // [1, 3]（值的列表）
len(map)                  // 元素个数
```

## 遍历

```mas-lang
for key, value in map:
    print("${key}: ${value}")
```

## 结构体键与复合值

```mas-lang
struct Person:
    name: string

var alice = Person("Alice")
var people: map<string,Person?> = {"leader": alice, "helper": null}
var scores: map<Person,int> = {alice: 90}
func main():
    alice.name = "Alice Chen"
    print(scores[alice]) // 90：修改字段不会改变对象身份
    print(scores.contains(Person("Alice Chen"))) // false：这是另一个对象
```

每个字典的键类型一致，值类型也一致。值可为基础值、结构体、可空值、列表或字典；`keys()` 和 `values()` 保留相应元素类型及共享引用。键支持基础类型或结构体引用，目前不接受可空键、容器键。固定数组值请改用列表。
