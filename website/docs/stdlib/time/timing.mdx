# 计时与休眠

单调时钟计时与线程休眠。

## monotonic_millis — 单调时钟毫秒计数

单调时钟用于测量时间间隔，不受系统时间跳变影响。

```mas-lang
let start: int = monotonic_millis()

// 执行某些操作...
let elapsed: int = monotonic_millis() - start
// elapsed 为经过的毫秒数
```

返回自系统启动以来的毫秒数，在同一进程内保证单调递增。

**注意**：`monotonic_millis` 的起点是系统启动时间，不是 Unix 纪元，**不可**用作墙钟时间。

## sleep — 线程休眠

阻塞当前线程至少指定的毫秒数。

```mas-lang
sleep(1000)   // 休眠至少 1000 毫秒（1 秒）
sleep(500)    // 休眠至少 500 毫秒
```

**注意**：传入负数会导致运行时错误。实际休眠时间可能略长于指定值，具体取决于操作系统调度精度。
