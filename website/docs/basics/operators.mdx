# 运算符

## 算术运算符

| 运算符 | 含义 | 示例 |
|--------|------|------|
| `+` | 加法 | `3 + 2` → `5` |
| `-` | 减法 | `5 - 2` → `3` |
| `*` | 乘法 | `3 * 2` → `6` |
| `/` | 除法（返回 float） | `6 / 2` → `3.0` |
| `%` | 取模（仅 int） | `7 % 3` → `1` |
| `%/%` | 整数除法（仅 int） | `7 %/% 2` → `3` |

`/` 除法总是返回 `float` 类型，即使两个操作数都是整数。`%` 和 `%/%` 仅支持 `int` 操作数。

整数加、减、乘和取负会检查溢出，包括复合赋值。`%/%` 和 `%` 的除数为零，或操作数为最小整数与 `-1` 时，报告带源码位置的运行时错误并以状态码 1 退出。整数除法向零截断，余数与被除数同号，例如 `-7 %/% 3` 为 `-2`，`-7 % 3` 为 `-1`。

`/` 保持浮点运算规则，浮点除零可以产生无穷或 NaN。

## 比较运算符

| 运算符 | 含义 |
|--------|------|
| `==` | 相等 |
| `!=` | 不等 |
| `<` | 小于 |
| `<=` | 小于等于 |
| `>` | 大于 |
| `>=` | 大于等于 |

比较运算返回 `bool` 类型。

- `<`、`<=`、`>`、`>=` 仅支持数值类型（`int`、`float`），可以混合比较，并保留整数的完整精度
- `==`、`!=` 要求两侧类型完全相同，支持 `int`、`float`、`bool`、`string`；列表、字典、固定数组、结构体和可空值不能直接用 `==` 比较（可空值只能与 `null` 比较），`int` 与 `float` 之间也不能用 `==`
- 比较是左结合的，不支持链式比较：`1 < 2 < 3` 会解析为 `(1 < 2) < 3` 并报类型错误

NaN 与任意浮点值（包括自身）的 `==` 均为 `false`，`!=` 均为 `true`；`<`、`<=`、`>`、`>=` 在任一侧为 NaN 时都返回 `false`。正负零比较相等。

## 逻辑运算符

```mas-lang
true and false   // false
true or false    // true
not true         // false
```

`and` 和 `or` 只接受 `bool` 操作数，并支持短路求值：

```mas-lang
if x != 0 and y / x > 1 :  // 当 x == 0 时不会计算 y / x
    print("ok")
```

`not` 的优先级高于比较运算，所以 `not a == b` 会解析为 `(not a) == b`；要表达“a 不等于 b”请写 `not (a == b)`。

## 字符串拼接

`+` 运算符可用于字符串拼接：

```mas-lang
"Hello, " + "world"   // "Hello, world"
```

`+` 的两侧必须同为 `string`；字符串和数字不能直接相加，需要先用 `string()` 转换。

## 运算符优先级

从低到高：

1. `or`
2. `and`
3. `==` `!=`
4. `<` `<=` `>` `>=`
5. `+` `-`
6. `*` `/` `%` `%/%`
7. `-`（负号）、`not`
8. 函数调用、索引 `[]`、成员访问 `.`、切片 `[:]`

使用括号 `()` 改变运算顺序。`..` 只用于 `for` 范围，不参与表达式优先级，详见[运算符优先级](../appendix/operator-precedence)。
