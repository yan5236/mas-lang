# 类型系统

Mas lang 是静态类型语言，每个值都有确定的类型。

## 基本类型

| 类型 | 描述 | 示例 |
|------|------|------|
| `int` | 64 位有符号整数 | `42`、`-3` |
| `float` | 64 位浮点数 | `3.14`、`-0.5` |
| `bool` | 布尔值 | `true`、`false` |
| `string` | UTF-8 字符串 | `"你好"`、`"hello"` |

`int` 的范围为 `-9223372036854775808` 到 `9223372036854775807`，两端均可直接写为字面量。整数运算超出范围时报告运行时错误，不会回绕；超出范围的整数字面量在编译期就会被拒绝。

## 复合类型

| 类型 | 描述 | 示例 |
|------|------|------|
| `list<T>` | 动态数组 | `[1, 2, 3]` |
| `map<K,V>` | 键值对字典 | `{"a": 1}` |
| `array<T,N>` | 固定长度数组 | `array<int,3>(1,2,3)` |

使用 [`struct`](../data-structures/struct) 可以定义自己的复合类型；使用 [`T?`](./nullable) 可以表示一个值也可能是 `null`。例如 `Person` 表示一个人，`Person?` 表示一个人或没有人。

## 类型标注

在变量或参数名后加 `: 类型` 进行类型标注：

```mas-lang
var count: int = 0
var price: float = 9.99
var name: string = "Mas lang"
var items: list<int> = [1, 2, 3]
var user: map<string, int> = {"age": 18}
var fixed: array<int, 3>
```

定长数组是唯一允许省略初始化值的类型标注；省略时所有槽位为零值。

## 类型推断

若声明时提供了初始值，可省略类型标注：

```mas-lang
var count = 0        // 推断为 int
var price = 9.99     // 推断为 float
var name = "Mas lang" // 推断为 string
var items = [1, 2, 3] // 推断为 list<int>
```

空列表、空字典没有可推断的元素类型，必须提供显式标注，例如 `var items: list<int> = []`、`var table: map<string,int> = {}`。

## unit 类型

没有 `->` 返回标注的函数，其返回类型是 `unit`（类似于其他语言中的 void）。

`unit` 只存在于类型系统中，**不能写成类型标注**：`func f() -> unit:` 会报“未知类型 `unit`”。省略 `-> 类型` 即可：

```mas-lang
func greet(name: string):
    print("Hello " + name)
// 该函数返回 unit，无需 return 语句
```

## 类型限制

- 动态容器（`list` 的元素、`map` 的值）可以是基本类型、结构体、可空值、列表或字典，**支持嵌套**，例如 `list<list<int>>`、`map<string,list<int>>`
- 动态容器里不能放定长数组（`list<array<int,3>>` 会编译失败）；需要这种结构时改用嵌套列表
- 固定数组的元素可以是基本类型、结构体、可空值、列表、字典或嵌套数组，例如 `array<array<int,2>,2>`
- `map` 的键只支持基本类型或结构体引用，不支持可空键和容器键
- `int` 和 `float` 混合算术时，`int` 会自动提升为 `float`；不会反向把 `float` 截断成 `int`，例如 `var x: int = 1 + 2.5` 会报类型错误
- 使用 `<`、`<=`、`>`、`>=` 比较时支持 `int` 与 `float` 混合，并保留整数的完整精度（`9223372036854775807 < 9223372036854775808.0` 为 `true`）。任何一侧为 NaN 时，这四个比较都返回 `false`
- `==`、`!=` 要求两侧类型完全相同，且不能用于列表、字典、固定数组、结构体或可空值；可空值只能与 `null` 比较。`int` 与 `float` 之间不能直接使用 `==`，请先显式转换
