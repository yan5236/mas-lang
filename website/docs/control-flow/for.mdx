# for 循环

## 范围循环

使用 `for i in start..end` 遍历整数范围（左闭右开）：

```mas-lang
for i in 0..5:
    print(i)
// 输出 0 1 2 3 4
```

起点和终点都可以是完整的整数表达式，例如 `for i in 0..len(items)`；也支持负数端点。起点大于等于终点时循环体一次都不执行。

## 遍历列表

```mas-lang
var items = ["苹果", "香蕉", "橙子"]
for item in items:
    print(item)
```

列表遍历只能声明一个循环变量；声明两个变量会报错。

## 遍历字典

遍历字典的键和值，必须同时声明两个循环变量（同一个字典的键类型、值类型必须一致）：

```mas-lang
var user = {"name": "张三", "city": "上海"}
for key, value in user:
    print("${key}: ${value}")
```

只写一个变量会报“遍历字典时必须同时声明键和值变量”。只需要键时，遍历 `keys()`：

```mas-lang
for key in user.keys():
    print(key)
```

需要混合类型的字段请用结构体，字典的值类型必须一致。

## 不能直接遍历的类型

`for-in` 目前只支持列表和字典。固定数组要用下标范围循环，字符串也不支持直接遍历：

```mas-lang
var arr = array<int, 3>(1, 2, 3)
for i in 0..len(arr):
    print(arr[i])
```

## break 和 continue

`break` 和 `continue` 同样适用于 for 循环：

```mas-lang
for i in 0..10:
    if i % 2 == 0:
        continue
    print(i)
// 输出奇数：1 3 5 7 9
```

循环变量只存在于循环体内，循环结束后不能继续访问。
