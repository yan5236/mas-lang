# 导入

## 导入语法

使用 `import` 导入其他模块中的公开符号：

```mas-lang
// 导入特定符号
import utils.math { add, sub }

// 重命名导入的函数，末项可以保留逗号
import time {
    sleep as time_sleep,
    unix_seconds,
}

// 为模块设置别名，只通过 t 访问花括号内列出的成员
import time as t {
    sleep,
    unix_millis as millis,
}

func main():
    time_sleep(10)
    t.sleep(10)
    print(t.millis())
```

```mas-lang
// 通配导入
import utils.math.*

// 导入已安装的标准库包
import time { unix_seconds }
```

具名列表可以写在一行，也可以换行。项目内同一个文件的模块别名必须唯一，并且不能和顶层声明或直接导入的名字重复。重导出支持列表换行、尾逗号和成员别名。

具名导入、通配导入和重导出共用当前文件的导入名称。若两个不同的符号占用同一个名称，编译器会报错。可用成员别名或模块别名区分它们。重复导入同一个符号并使用同一个名称是允许的。

## 模块路径

- 路径使用点分隔：`utils.math` 对应 `src/utils/math.ms`
- `index.ms` 是目录入口文件，路径 `utils` 对应 `src/utils/index.ms`

## local 前缀

当本地模块与外部包名冲突时，使用 `local.` 前缀强制指向本地模块：

```mas-lang
import local.time { format }
```

## 导入解析顺序

1. 顶层名称匹配 `settings.toml` 中的 `[dependencies]` 时，按声明版本查找已安装的包。
2. 其他名称解析到 `src/` 下的本地模块。
