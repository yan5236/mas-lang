# 导入

## 前置条件

`import` 和 `export import` 通常需要项目上下文：入口文件向上能找到 `settings.toml`。只有一个 `.ms` 文件（例如 `maslang run hello.ms`，目录里没有 `settings.toml`）时，只有随附标准库 `io` 可以解析，其他导入仍会报“模块导入应在语义分析前完成展开”。需要导入项目内模块或第三方包时，用 `fama new` 建工程，或手动提供项目配置。

## 导入语法

使用 `import` 导入其他模块中的公开符号：

```mas-lang
// 导入特定符号
import utils.math { add, sub }

// 重命名导入的函数，末项可以保留逗号
import time {
    sleep as time_sleep,
    unix_seconds,
}

// 为模块设置别名，只通过 t 访问花括号内列出的成员
import time as t {
    sleep,
    unix_millis as millis,
}

func main():
    time_sleep(10)
    t.sleep(10)
    print(t.millis())
```

模块别名导入的成员只能通过别名访问（上例是 `t.sleep`、`t.millis`），不会把 `sleep` 直接引入当前文件。成员别名（`unix_millis as millis`）在别名模块内同样写作 `t.millis`。

```mas-lang
// 通配导入
import utils.math.*

// 导入已安装的依赖包（需在 settings.toml 声明并执行 fama install）
import time { unix_seconds }

// 随附标准库不需要声明依赖，直接导入即可
import io { stdout, write_text_to }
```

具名列表可以写在一行，也可以换行，并允许尾逗号。项目内同一个文件的模块别名必须唯一，并且不能和顶层声明或直接导入的名字重复。

具名导入、通配导入和重导出共用当前文件的导入名称。若两个不同的符号占用同一个名称，编译器会报错；可用成员别名或模块别名区分。重复导入同一个符号并使用同一个名称是允许的。

具名导入的可见名也不能与本文件中同名的顶层声明（`func`、`struct`、`var`、`const`）重名，否则会报“导入名 … 与当前模块顶层声明重名”。

## 模块路径

- 路径使用点分隔：`utils.math` 对应 `src/utils/math.ms`
- `index.ms` 是目录入口文件，路径 `utils` 对应 `src/utils/index.ms`
- 路径**始终从包根目录的 `src/` 开始解析**，与书写导入语句的文件所在目录无关。例如在 `src/utils/index.ms` 里引用同目录的 `math.ms`，必须写 `utils.math`，不能写 `math`

## local 前缀

当本地模块与外部包名冲突时，使用 `local.` 前缀强制指向本地模块：

```mas-lang
import local.time { format }
```

## 导入解析顺序

判断以**发出导入的包自己的** `settings.toml` 为准：

1. 顶层名称匹配当前包 `[dependencies]` 时，按声明版本查找已安装的包。
2. 顶层名称是随附标准库（目前是 `io`）且当前包没有声明同名依赖时，指向随工具链分发的包；它优先于项目内同名源码。
3. 其他名称解析到 `src/` 下的本地模块。

`local.` 前缀跳过前两步，始终解析项目内源码。依赖包必须先用 `fama add` 声明、再用 `fama install` 安装到 `mod_module/<name>@<version>/`；缺失时会提示“未安装依赖 …，请先执行 fama install”。随附标准库不需要安装，也不会写进 `mod-lock.yml`；第三方包同样可以省略自己的 `io` 依赖声明，它导入的是随附 io。

同一个可执行程序的模块图如果实际加载了随附 `io` 与显式声明的 `io` 两套原生实现，链接前会报错，并提示移除 `[dependencies].io` 后改用随附版，或让所有导入方显式声明同一份依赖。仅声明但没有导入不构成冲突。
