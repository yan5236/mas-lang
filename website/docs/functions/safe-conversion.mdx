# 安全转换

安全转换函数在转换失败时不会产生运行时错误，而是返回一个结果对象，可通过 `.ok` 和 `.value` 判断转换是否成功。

## try_int()

```mas-lang
var result = try_int("123")
if result.ok:
    print(result.value)   // 123
else:
    print("转换失败")
```

## try_float()

```mas-lang
var result = try_float("3.14")
if result.ok:
    print(result.value)   // 3.14
```

## try_bool()

```mas-lang
var result = try_bool("true")
if result.ok:
    print(result.value)   // true
```

`try_bool(string)` 只接受精确的小写 `"true"` 和 `"false"`；`"TRUE"` 等写法会得到 `ok=false`。

## 返回值结构

安全转换函数返回一个内部结果值（诊断信息中显示为 `try_result<T>`），包含两个只读属性：

| 属性 | 类型 | 说明 |
|------|------|------|
| `.ok` | bool | 转换是否成功 |
| `.value` | T | 转换后的值（仅在 ok 为 true 时有效） |

失败时 `.value` 是一个无害占位值：`try_int` 为 `0`、`try_float` 为 `0.0`、`try_bool` 为 `false`。请先判断 `.ok`，不要依赖失败时的内容。

`try_string()` 不存在，因为字符串转换几乎不会失败。

## 输入类型与规则

`try_int`、`try_float`、`try_bool` 都接受基础类型（`int`、`float`、`bool`、`string`），不接受容器、结构体和可空值。

- `try_int` 接受整数、布尔值、字符串和浮点数。整数与布尔值转换总是成功；字符串必须是纯十进制整数，不裁剪空白：`try_int(" 12")` 的 `ok` 为 `false`
- `try_float` 的字符串解析接受小数和指数写法，`"inf"`、`"nan"` 也算合法浮点数（`ok=true`）
- `try_int(float)` 先检查范围，再向零截断小数部分。NaN、正负无穷，以及小于 `-9223372036854775808.0` 或大于等于 `9223372036854775808.0` 的值返回 `ok=false`，`value` 为 `0`

`int(float)` 使用同一范围检查，失败时报告带源码位置的运行时错误并以状态码 1 退出；`int(string)` 的解析失败则不带源码位置。

例如：

```mas-lang
var result = try_int(true)   // result.ok == true, result.value == 1
```

```mas-lang
var huge = try_int(float("1e20"))
func main():
    print(huge.ok)      // false
    var small = try_int(-3.9)
    print(small.value)  // -3
```

浮点转整数检查的是已经舍入为 64 位浮点数的值，可用范围是 `[-2^63, 2^63)`。例如 `-9223372036854776000.0` 和 `-9223372036854775809.0` 都会先舍入为精确的 `-2^63`，因此转换成功；真正更小的相邻值 `-9223372036854777856.0` 转换失败。`9223372036854775807.0` 则会舍入为 `2^63`，因此转换失败。需要精确保留十进制整数时，使用整数字面量或 `try_int("...")`，不要先经过 `float`。
