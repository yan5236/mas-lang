# 内置函数

内置函数全局可用，无需导入。

## print — 打印输出

```mas-lang
func main():
    print(42)
    print(3.14)
    print(true)
    print("你好")
```

`print` 只接受基础类型（`int`、`float`、`bool`、`string`），并且只能接收一个参数。列表、字典、固定数组、结构体、可空值和 `null` 不能直接打印：需要逐个元素打印，或先转成字符串。

`print` 只能在函数体内调用，顶层语句里调用会编译失败。

浮点数按最短往返表示输出：`print(3.0)` 输出 `3`，`print(3.5)` 输出 `3.5`，`print(1.0 / 0.0)` 输出 `inf`。

## try_print — 可恢复打印

```mas-lang
func main():
    if not try_print("日志"):
        print("标准输出不可用，改走别的路径")
```

`try_print` 接受与 `print` 相同的基础类型和参数个数，返回 `bool`：写入成功为 `true`，标准输出不可写（例如管道读端已关闭）为 `false`，调用方可以继续执行。`try_print` 同样只能在函数体内调用。

`print` 在写入失败时会报告带中文消息的运行时错误并以状态码 1 退出，不会产生 Rust panic；需要继续执行时改用 `try_print`。

## len — 获取长度

```mas-lang
len("hello")      // 5
len([1, 2, 3])    // 3
len({"a": 1})     // 1
len(array<int, 3>(1, 2, 3)) // 3
```

`len` 可用于 `string`、`list`、`map`、`array`，返回 `int`。

- 字符串按 Unicode 标量（字符）计数，不是 UTF-8 字节数：`len("你好")` 为 `2`，`len("👍")` 为 `1`
- 组合字符可能由多个标量组成：`len("é")`（`e` + 组合尖音符）为 `2`；预组合字符 `é` 则为 `1`
- 数组返回固定长度，但实参表达式仍会先求值（如果有副作用会执行）

## 类型转换

将值从一种基础类型转换为另一种类型。转换失败时会产生运行时错误。

### int()

```mas-lang
int(3.14)     // 3（向零截断）
int(-3.14)    // -3
int("123")    // 123
int("-123")   // -123
int(true)     // 1
int(false)    // 0
```

- `int(float)` 向零截断小数；数值非有限（NaN、正负无穷）或超出 `int` 范围时报运行时错误
- `int(string)` 只接受纯十进制整数，不接受空白、小数或指数写法：`int(" 12")`、`int("3.9")` 都会失败
- 字符串解析失败的错误消息是 `字符串无法转换为 int`，不附带源码位置；浮点越界错误则带源码位置

### float()

```mas-lang
float(42)     // 42.0（值是 float；print 显示为 42）
float("3.14") // 3.14
float("1e3")  // 1000
float(true)   // 1.0
```

`float(string)` 接受小数和指数写法，也接受 `"inf"`、`"nan"`。字符串解析失败时报 `字符串无法转换为 float`。

### string()

```mas-lang
string(42)    // "42"
string(3.14)  // "3.14"
string(3.0)   // "3"（整数值浮点不补 .0）
string(true)  // "true"
```

`string(float)` 使用最短往返表示：`string(0.1 + 0.2)` 是 `"0.30000000000000004"`，`string(-0.0)` 是 `"-0"`。

### bool()

```mas-lang
bool(0)       // false
bool(42)      // true
bool(-1)      // true
bool(0.0)     // false
bool(0.5)     // true
bool("")      // false
bool("abc")   // true
bool("false") // true：非空字符串就是 true
```

- 数值为零时为 `false`，非零为 `true`；NaN 也是 `true`
- 字符串按长度判断：空串为 `false`，非空串为 `true`

### 失效转换

```mas-lang
int("abc")     // 运行时错误：字符串无法转换为 int
float("xyz")   // 运行时错误：字符串无法转换为 float
```

这类字符串解析错误以状态码 1 退出，且不附带源码位置。若需安全转换避免运行时错误，参见[安全转换](./safe-conversion)。

## 受检整数运算

`+`、`-`、`*`、`%/%`、`%` 和一元 `-` 遇到溢出或除零时会报告源码位置并以状态码 1 退出。如果希望自己决定失败后怎么处理，改用下面这组内建函数：它们不会中止程序，而是把结果包装成 `try_result<int>`。

```mas-lang
func main():
    var sum = try_add(9223372036854775807, 1)
    print(sum.ok)     // false
    print(sum.value)  // 0：失败时的占位值

    var quotient = try_div(10, 0)
    print(quotient.ok)  // false
```

| 内建 | 对应严格运算 | 返回 `ok=false` 的条件 |
| --- | --- | --- |
| `try_add(a, b)` | `a + b` | 有符号加法溢出 |
| `try_sub(a, b)` | `a - b` | 有符号减法溢出 |
| `try_mul(a, b)` | `a * b` | 有符号乘法溢出 |
| `try_div(a, b)` | `a %/% b` | `b == 0`，或 `a` 为 `int` 最小值且 `b` 为 `-1` |
| `try_mod(a, b)` | `a % b` | 与 `try_div` 相同 |
| `try_neg(a)` | `-a` | `a` 为 `int` 最小值 |

- 参数必须是 `int`，返回 `try_result<int>`：`.ok` 表示是否成功，`.value` 只在 `.ok` 为 `true` 时有意义
- 失败时 `.value` 是占位值 `0`，调用方应先判断 `.ok`，不要直接依赖 `.value`
- 结果结构与[安全转换](./safe-conversion)中的 `try_int` 等一致
- 除法与取余和严格运算符一样向零截断：`try_div(-7, 3)` 得到 `-2`，`try_mod(-7, 3)` 得到 `-1`
- 合法边界照常成功：`try_add(9223372036854775806, 1)` 得到 `9223372036854775807`
- 严格运算符与复合赋值（`+=`、`-=`、`*=`、`%=`）行为不变：溢出或除零仍然报错退出
