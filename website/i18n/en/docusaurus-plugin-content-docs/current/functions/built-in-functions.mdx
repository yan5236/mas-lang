# Built-in Functions

Built-in functions are globally available without any import.

## print — Print Output

```mas-lang
func main():
    print(42)
    print(3.14)
    print(true)
    print("hello")
```

`print` accepts only primitive types (`int`, `float`, `bool`, `string`) and takes exactly one argument. Lists, dictionaries, fixed arrays, structs, nullable values, and `null` cannot be printed directly: print them element by element, or convert them to a string first.

`print` can only be called inside a function body; calling it from a top-level statement fails to compile.

Floats print in shortest round-trip form: `print(3.0)` outputs `3`, `print(3.5)` outputs `3.5`, `print(1.0 / 0.0)` outputs `inf`.

## try_print — Recoverable Printing

```mas-lang
func main():
    if not try_print("log line"):
        print("standard output is unavailable, take another path")
```

`try_print` accepts the same primitive types and argument count as `print` and returns `bool`: `true` when the write succeeded, `false` when standard output is not writable (for example, the read end of a pipe is closed). The caller can keep running. Like `print`, it can only be called inside a function body.

When the write fails, `print` reports a runtime error with a Chinese message and exits with status code 1; it never panics. Use `try_print` when execution must continue.

## len — Get Length

```mas-lang
len("hello")      // 5
len([1, 2, 3])    // 3
len({"a": 1})     // 1
len(array<int, 3>(1, 2, 3)) // 3
```

`len` works with `string`, `list`, `map`, and `array`, returning an `int`.

- Strings count Unicode scalars (characters), not UTF-8 bytes: `len("你好")` is `2` and `len("👍")` is `1`
- A combining character may consist of several scalars: `len("é")` (an `e` plus a combining acute accent) is `2`, while a precomposed `é` is `1`
- An array returns its fixed length, but the argument expression is still evaluated first (side effects still happen)

## Type Conversion

Convert a value from one primitive type to another. Failed conversions produce a runtime error.

### int()

```mas-lang
int(3.14)     // 3 (truncation toward zero)
int(-3.14)    // -3
int("123")    // 123
int("-123")   // -123
int(true)     // 1
int(false)    // 0
```

- `int(float)` truncates the fraction toward zero; a non-finite value (NaN, positive or negative infinity) or one outside the `int` range reports a runtime error
- `int(string)` accepts pure decimal integers only — no whitespace, decimals, or exponent notation: both `int(" 12")` and `int("3.9")` fail
- A string parse failure reports a conversion error without a source location, while a float range error does carry one

### float()

```mas-lang
float(42)     // 42.0 (the value is a float; print shows 42)
float("3.14") // 3.14
float("1e3")  // 1000
float(true)   // 1.0
```

`float(string)` accepts decimal and exponent notation, and also `"inf"` and `"nan"`. A parse failure reports a conversion error.

### string()

```mas-lang
string(42)    // "42"
string(3.14)  // "3.14"
string(3.0)   // "3" (an integral float gets no trailing .0)
string(true)  // "true"
```

`string(float)` uses shortest round-trip form: `string(0.1 + 0.2)` is `"0.30000000000000004"` and `string(-0.0)` is `"-0"`.

### bool()

```mas-lang
bool(0)       // false
bool(42)      // true
bool(-1)      // true
bool(0.0)     // false
bool(0.5)     // true
bool("")      // false
bool("abc")   // true
bool("false") // true: any non-empty string is true
```

- Numbers are `false` when zero and `true` otherwise; NaN is `true` as well
- Strings are judged by length: the empty string is `false` and any non-empty string is `true`

### Failed Conversions

```mas-lang
int("abc")     // runtime error: cannot convert string to int
float("xyz")   // runtime error: cannot convert string to float
```

These string parse errors exit with status code 1 and carry no source location. For safe conversions that avoid runtime errors, see [Safe Conversion](./safe-conversion).

## Checked Integer Arithmetic

`+`, `-`, `*`, `%/%`, `%`, and unary `-` report the source location and exit with status code 1 on overflow or division by zero. To decide what happens after such a failure yourself, use the built-ins below: they never abort the program and instead return `try_result<int>`.

```mas-lang
func main():
    var sum = try_add(9223372036854775807, 1)
    print(sum.ok)     // false
    print(sum.value)  // 0: the placeholder value on failure

    var quotient = try_div(10, 0)
    print(quotient.ok)  // false
```

| Built-in | Strict operator | Condition for `ok=false` |
| --- | --- | --- |
| `try_add(a, b)` | `a + b` | Signed addition overflows |
| `try_sub(a, b)` | `a - b` | Signed subtraction overflows |
| `try_mul(a, b)` | `a * b` | Signed multiplication overflows |
| `try_div(a, b)` | `a %/% b` | `b == 0`, or `a` is the minimum `int` and `b` is `-1` |
| `try_mod(a, b)` | `a % b` | Same as `try_div` |
| `try_neg(a)` | `-a` | `a` is the minimum `int` |

- Arguments must be `int`; the result is `try_result<int>`, where `.ok` reports success and `.value` is meaningful only when `.ok` is `true`
- On failure `.value` is the placeholder `0`; check `.ok` first and never rely on `.value`
- The result structure matches `try_int` and the other functions on the [Safe Conversion](./safe-conversion) page
- Division and remainder truncate toward zero like the strict operators: `try_div(-7, 3)` is `-2` and `try_mod(-7, 3)` is `-1`
- Valid boundaries still succeed: `try_add(9223372036854775806, 1)` is `9223372036854775807`
- Strict operators and compound assignment (`+=`, `-=`, `*=`, `%=`) are unchanged: overflow or division by zero still reports an error and exits
