# for Loops

## Range Loops

Use `for i in start..end` to iterate over an integer range (half-open):

```mas-lang
for i in 0..5:
    print(i)
// prints 0 1 2 3 4
```

Both endpoints may be full integer expressions, e.g. `for i in 0..len(items)`; negative endpoints are supported too. When the start is greater than or equal to the end, the body never runs.

## Iterating Over Lists

```mas-lang
var items = ["apple", "banana", "orange"]
for item in items:
    print(item)
```

List iteration takes exactly one loop variable; declaring two is an error.

## Iterating Over Maps

Iterating over a map's keys and values requires two loop variables (within one map the key type and the value type must each be uniform):

```mas-lang
var user = {"name": "Alice", "city": "Shanghai"}
for key, value in user:
    print("${key}: ${value}")
```

Declaring only one variable reports that iterating a map requires both a key and a value variable. When you only need the keys, iterate over `keys()`:

```mas-lang
for key in user.keys():
    print(key)
```

Use a struct when fields need mixed types — a map's value type must be uniform.

## Types You Cannot Iterate Directly

`for-in` currently supports lists and maps only. Fixed arrays need an index range loop, and strings cannot be iterated directly:

```mas-lang
var arr = array<int, 3>(1, 2, 3)
for i in 0..len(arr):
    print(arr[i])
```

## break and continue

`break` and `continue` work in for loops as well:

```mas-lang
for i in 0..10:
    if i % 2 == 0:
        continue
    print(i)
// prints odd numbers: 1 3 5 7 9
```

The loop variable exists only inside the loop body and cannot be accessed after the loop ends.
