# Keywords and Built-in Names

## Keywords (Reserved Words)

The following identifiers are language keywords. They cannot be used as variable names, function names, or struct names:

| Name | Category | Purpose |
|------|----------|---------|
| `and` | keyword | Logical AND |
| `as` | keyword | Import alias |
| `break` | keyword | Exit a loop |
| `const` | keyword | Declare a constant |
| `continue` | keyword | Skip to next loop iteration |
| `elif` | keyword | Else if |
| `else` | keyword | Else |
| `export` | keyword | Re-export (used with import) |
| `extern` | keyword | Declare a native C function |
| `false` | literal | Boolean false |
| `for` | keyword | For loop |
| `func` | keyword | Define a function |
| `if` | keyword | Conditional |
| `import` | keyword | Import a module |
| `in` | keyword | Iteration target |
| `not` | keyword | Logical NOT |
| `null` | literal | The empty value of a nullable type |
| `or` | keyword | Logical OR |
| `pub` | keyword | Public visibility |
| `return` | keyword | Return a value |
| `struct` | keyword | Define a struct with indentation |
| `true` | literal | Boolean true |
| `var` | keyword | Declare a variable |
| `while` | keyword | While loop |

## Built-in Functions (Not Keywords)

The names below are globally available built-in functions. They **can** be used as variable names, but cannot be used to define a function or struct of the same name:

| Name | Purpose |
|------|---------|
| `print` | Print output (primitive types only) |
| `len` | Length of a string, list, map, or array |
| `int` `float` `string` `bool` | Primitive type conversion |
| `try_int` `try_float` `try_bool` | Safe conversion, returning a result with `ok`/`value` |

For example `var print = 1` is legal, but `func print(...)` and `struct print:` report that a built-in name cannot be shadowed.

`int`, `float`, `string`, `bool`, `list`, `map`, and `array` are also type names, but they are not keywords themselves: `var int = 1` and `var list = 1` compile. `main` is not a keyword, but a struct cannot be named `main`, and an executable program must define a parameterless `func main()`.
