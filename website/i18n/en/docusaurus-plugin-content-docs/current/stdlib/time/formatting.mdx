# Time Formatting

Format the current UTC time as standard strings.

## now_utc — ISO 8601 Format

```mas-lang
var s: string = now_utc()
// example: "2026-05-30T12:34:56+00:00"
```

Returns an RFC 3339 / ISO 8601 formatted UTC string with a fixed `+00:00` offset. Suitable for data interchange, log files, and API responses.

## now_email_date — RFC 2822 Format

```mas-lang
var s: string = now_email_date()
// example: "Fri, 30 May 2026 12:34:56 +0000"
```

Returns an RFC 2822 formatted UTC string using English weekday and month abbreviations. Suitable for email and other legacy protocols.

## now_http_date — HTTP-date Format

```mas-lang
var s: string = now_http_date()
// example: "Fri, 30 May 2026 12:34:56 GMT"
```

Returns an RFC 7231 HTTP-date formatted UTC string with `GMT` timezone identifier. Suitable for HTTP headers such as `Date`, `Last-Modified`, and `Expires`.
