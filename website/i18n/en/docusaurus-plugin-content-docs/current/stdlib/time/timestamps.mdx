# Timestamps

Get the current Unix timestamp.

## unix_seconds — Current Unix Timestamp (Seconds)

```mas-lang
var ts: int = unix_seconds()
// example: 1717050800
```

Returns the number of seconds since the Unix epoch (1970-01-01 00:00:00 UTC). Suitable for logging, time-window checks, and signatures.

## unix_millis — Current Unix Timestamp (Milliseconds)

```mas-lang
var ts: int = unix_millis()
// example: 1717050800123
```

Returns the number of milliseconds since the Unix epoch, with higher precision than `unix_seconds`. Suitable for scenarios requiring finer-grained timestamps.
