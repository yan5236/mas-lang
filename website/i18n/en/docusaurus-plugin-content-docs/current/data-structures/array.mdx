# Fixed Arrays

## Type

`array<T,N>` is a fixed-length array. The length N is determined at compile time:

```mas-lang
var arr: array<int, 3>
```

When the initializer is omitted, every slot holds the zero value (numeric `0`, `false` for `bool`, empty for references and strings).

## Initialization

```mas-lang
var arr = array<int, 3>(1, 2, 3)
```

The initializer must supply exactly N elements, each matching the declared element type.

## Index Access

```mas-lang
arr[0]   // 1
arr[2]   // 3
```

Valid indices are `0 <= index < N`. A negative or out-of-range index (for either read or write) reports a runtime error with a source location and exits with status code 1 — it never returns arbitrary memory.

## Recoverable Index Access

Use `try_get`/`try_set` when you want to handle the failure yourself: a failure never terminates the program and never modifies the elements.

```mas-lang
func main():
    var arr = array<int, 3>(10, 20, 30)

    var hit = arr.try_get(1)      // ok = true, value = 20
    var miss = arr.try_get(3)     // ok = false
    print(arr.try_get(-1).ok)     // false

    print(arr.try_set(1, 99))     // true, arr becomes (10, 99, 30)
    print(arr.try_set(3, 99))     // false, arr stays (10, 99, 30)
    print(arr[1])                 // 99
```

| Method | Returns | Notes |
|--------|---------|-------|
| `try_get(i)` | `try_result<T>` | Succeeds only when `0 <= i < N`; otherwise `ok = false` |
| `try_set(i, v)` | `bool` | Writes only for a valid index; otherwise returns `false` and keeps the old value |

As with lists, check `.ok` first and read `.value` only on success; on failure `.value` is just a placeholder. `try_set` needs an array that has a stable storage location (an array held by a variable or a struct field). An array element is a copy, so expressions such as `grid[0]` or an array returned by a function have no writable address and `try_set` on them is rejected at compile time; use an index assignment like `grid[0][1] = v` for that case.

## Difference from List

| Feature | list | array |
|---------|------|-------|
| Length | Grows dynamically | Fixed at compile time |
| Methods | append, remove, pop, etc. | No add/remove methods |
| Storage | Heap-allocated, shared handle | Inline value; local arrays live in the stack frame |
| Iteration | `for-in` supported | No `for-in`; use an index range loop |
| Slicing | Supported | Not supported |

```mas-lang
var arr = array<int, 3>(1, 2, 3)
len(arr)          // 3

for i in 0..len(arr):
    print(arr[i])
```

`0..len(arr)` is a half-open range that covers every index exactly. `for i in 0..3:` works as well.

## Structs and Nullable Elements

```mas-lang
struct Person:
    name: string

var people = array<Person?,2>(Person("Alice"), null)
func main():
    people[1] = Person("Bob")
    print(people[1].value.name)
```

Array elements may be primitives, structs, nullable values, lists, dictionaries, or nested arrays, e.g. `array<list<int>,2>`, `array<array<int,2>,2>`. When initializing nested arrays, spell out the inner arrays:

```mas-lang
var grid = array<array<int, 2>, 2>(array<int, 2>(1, 2), array<int, 2>(3, 4))
```

Array assignment copies the array slots; struct, list, and dictionary elements still share object references. A nested index assignment writes back into the original array position:

```mas-lang
var grid = array<array<int, 2>, 2>(array<int, 2>(1, 2), array<int, 2>(3, 4))
grid[0][1] = 9
print(grid[0][1]) // 9
```

A fixed array is an inline value and cannot be placed directly inside a list or as a map value; use a list when you need a dynamic container.
