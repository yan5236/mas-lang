# Lists

## Type and Literals

`list<T>` is a dynamic array; it stores same-typed primitives, structs, nullable values, lists, or dictionaries:

```mas-lang
var list = [1, 2, 3, 4]           // list<int>
var names: list<string> = ["a", "b"]
var empty: list<int> = []
```

An empty list `[]` has no element type to infer, so it must appear in an explicit `list<T>` annotation or a parameter type context. Lists can also be nested, e.g. `var rows: list<list<int>> = [[], [1, 2]]`; a dynamic list cannot hold fixed arrays (`list<array<int,3>>` fails to compile).

## Indexing

Indexes start at 0:

```mas-lang
var list = [10, 20, 30]
list[0]   // 10
list[2]   // 30
```

A negative or out-of-range index reports a runtime error and exits with status code 1.

## Slicing

```mas-lang
var list = [1, 2, 3, 4, 5]
list[1:3]   // [2, 3]
list[:3]    // [1, 2, 3]
list[2:]    // [3, 4, 5]
```

Slice ranges are half-open (start inclusive, end exclusive); a negative or out-of-range range reports a runtime error, and a step is not supported. Slicing copies the element slots into a new list, but struct, list, and dictionary elements still share the original object references.

## List Methods

```mas-lang
var list = [1, 2, 3]

list.append(4)              // [1, 2, 3, 4]
list.remove(2)              // removes the first 2, list is [1, 3, 4]
list.pop()                  // returns 4, list is [1, 3]
list.pop(0)                 // returns 1, list is [3]
list.sort()                 // sort in place
list.reverse()              // reverse in place
list.index(3)               // returns the element index
list.contains(3)            // true
len(list)                   // length
```

| Method | Returns | Notes |
|--------|---------|-------|
| `append(v)` | nothing | Appends to the end |
| `remove(v)` | nothing | Removes the first element equal to `v`; reports a runtime error if absent |
| `pop()` | element type | Removes and returns the last element; an empty list reports a runtime error |
| `pop(i)` | element type | Removes and returns the element at index `i`; out of range reports a runtime error |
| `sort()` | nothing | Sorts ascending in place, following the rules below |
| `reverse()` | nothing | Reverses in place; elements need not be comparable |
| `index(v)` | `int` | Returns the index of the first match; reports a runtime error if absent |
| `contains(v)` | `bool` | Whether the element is present |
| `len(list)` | `int` | Element count |

`sort()` only supports lists whose elements are all `int`, `float`, `bool`, or `string`: `bool` sorts `false < true`, `string` sorts by UTF-8 byte order (case-sensitive), and `float` sorts by numeric value (`-0.0` equals `0.0`). The order stays deterministic when a float list contains NaN: every NaN sorts after all numbers, and NaNs are ordered among themselves by bit pattern. Lists of structs and lists of nullable elements do not support `sort()`, but they do support `reverse()`.

## Recoverable Access and Update

Index reads and writes, `index`, `remove`, `pop`, and slicing report an error and exit with status code 1 when they fail. Use the `try_*` methods below when you want to handle the failure yourself: a failure never terminates the program and never modifies the list.

```mas-lang
func main():
    var nums = [10, 20, 30]

    var hit = nums.try_get(1)        // ok = true, value = 20
    var miss = nums.try_get(5)       // ok = false
    print(hit.value)                 // 20

    print(nums.try_set(1, 99))       // true, nums becomes [10, 99, 30]
    print(nums.try_set(5, 99))       // false, nums stays [10, 99, 30]

    print(nums.try_index(99).ok)     // true
    print(nums.try_index(7).ok)      // false

    print(nums.try_remove(7))        // false, nums stays [10, 99, 30]
    print(nums.try_remove(99))       // true, nums becomes [10, 30]

    var empty: list<int> = []
    print(empty.try_pop().ok)        // false, nothing is removed
    print(nums.try_pop(9).ok)        // false, nums stays [10, 30]
    print(nums.try_pop().value)      // 30, nums becomes [10]

    var part = nums.try_slice(0, 1)  // ok = true, value is [10]
    print(nums.try_slice(2, 1).ok)   // false, a reversed range is invalid
```

| Method | Returns | Notes |
|--------|---------|-------|
| `try_get(i)` | `try_result<T>` | Succeeds only when `0 <= i < len`; otherwise `ok = false` |
| `try_set(i, v)` | `bool` | Writes only for a valid index; otherwise returns `false` and keeps the old value |
| `try_pop()` | `try_result<T>` | Returns `ok = false` for an empty list and removes nothing |
| `try_pop(i)` | `try_result<T>` | Returns `ok = false` when out of range and removes nothing |
| `try_index(v)` | `try_result<int>` | Returns `ok = false` when absent instead of reporting an error |
| `try_remove(v)` | `bool` | Returns `false` when absent; otherwise removes the first match |
| `try_slice(a, b)` | `try_result<list<T>>` | Succeeds only when `0 <= a <= b <= len` and returns a new list |

Check `.ok` first and read `.value` only on success. On failure the placeholder falls into two groups: scalars and strings can be read safely (`0`, `0.0`, `false`, a valid empty string); structs, lists, maps, and arrays containing managed elements have no safe placeholder, and reading `.value` directly reports a source-located language error and exits with status code 1. Every `try_*` failure keeps the list length, elements, and reference relationships unchanged, and the code after it keeps running. Like slicing, `try_slice` copies the element slots while struct, list, and dictionary elements still share the original object references. `try_pop(i)` evaluates the index argument first and then checks the receiver's current length: after a shrink the old index is rejected, and after a grow the new element can be popped.

When elements may be `null`, `.ok` tells the two cases apart: `try_get` with `ok = true` and `.value == null` means the position holds a `null` element, while `ok = false` means the index is invalid. `try_index` and `try_remove` match `null` elements as well.

## Iteration

```mas-lang
var items = ["apple", "banana", "orange"]
for item in items:
    print(item)
```

List iteration takes exactly one loop variable; a second variable is an error. Use a range loop when you only need the indices:

```mas-lang
for i in 0..len(items):
    print(items[i])
```

## Struct Elements

`list<Person>` can store a `Person` struct you already defined, and `[Person(...)]` infers the type. Lists support appending, index reads and writes, iteration, slicing, popping, and reversing; elements share object references. `contains/index/remove` match by object reference, and `sort()` does not support struct elements. See [structs](./struct) for a complete example.

`contains/index/remove` match nullable primitive elements by content (two `null` values are the same), while structs and containers match by object reference. `sort()` only supports non-nullable primitive elements. Fixed arrays are inline values and cannot currently be list elements; use nested lists for that shape.
