# Maps

## Type and Literals

`map<K,V>` is a key-value dictionary:

```mas-lang
var user = {"name": "Alice", "age": 18}   // map<string, int>
var scores: map<string, int> = {}
```

Multi-line format:

```mas-lang
var config = {
    "host": "localhost",
    "port": 8080,
    "debug": true,
}
```

## Key Access

```mas-lang
var user = {"name": "Alice", "age": 18}
user["name"]   // "Alice"
```

## Adding and Updating

```mas-lang
user["email"] = "alice@example.com"   // add new key
user["age"] = 19                       // update existing key
```

## Map Methods

```mas-lang
var map = {"a": 1, "b": 2, "c": 3}

map.remove("b")           // remove key "b"
map.contains("a")         // true
map.keys()                // ["a", "c"] (list of keys)
map.values()              // [1, 3] (list of values)
len(map)                  // number of entries
```

## Iteration

```mas-lang
for key, value in map:
    print("${key}: ${value}")
```
