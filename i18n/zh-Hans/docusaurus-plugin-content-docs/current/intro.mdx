# 教程介绍

在 **5 分钟内了解 Docusaurus**。

## 开始

通过 **创建一个新站点** 开始。

或者使用 **[docusaurus.new](https://docusaurus.new)** **立即尝试 Docusaurus**。

### 环境要求

- [Node.js](https://nodejs.org/en/download/) 版本 20.0 或以上：
  - 安装 Node.js 时，建议勾选所有与依赖相关的复选框。

## 生成新站点

使用 **classic 模板** 生成一个新的 Docusaurus 站点。

运行以下命令后，classic 模板将自动添加到您的项目中：

```bash
npm init docusaurus@latest my-website classic
```

您可以在命令提示符、PowerShell、终端或代码编辑器的任何集成终端中键入此命令。

此命令还会安装运行 Docusaurus 所需的所有必要依赖。

## 启动站点

运行开发服务器：

```bash
cd my-website
npm run start
```

`cd` 命令用于切换到您正在使用的目录。为了使用您新创建的 Docusaurus 站点，您需要在终端中导航到该目录。

`npm run start` 命令会在本地构建您的网站，并通过开发服务器提供服务，您可以在 http://localhost:3000/ 查看。

打开 `docs/intro.md`（本页面）并编辑一些内容：站点会自动重新加载并显示您的更改。
