# Markdown 功能

Docusaurus 支持 **[Markdown](https://daringfireball.net/projects/markdown/syntax)** 和一些 **额外功能**。

## Front Matter

Markdown 文档顶部可以包含称为 [Front Matter](https://jekyllrb.com/docs/front-matter/) 的元数据：

```text title="my-doc.md"
// highlight-start
---
id: my-doc-id
title: 我的文档标题
description: 我的文档描述
slug: /my-custom-url
---
// highlight-end

Markdown 内容
```

## 标题

Markdown 标题使用标准的 "#" 语法，并会自动添加到目录中。`#` 的数量对应标题级别。

```md
## 标题

我的文本
```

### 标题 ID

在标题文本后添加 `{/* #my-custom-id */}` 可以为其分配一个显式的锚点 ID，用于链接。

```md
### 标题 ID {/_ #my-custom-id _/}
```

## 链接

支持常规 Markdown 链接，可以使用 URL 路径或相对文件路径。

```md
让我们看看如何[创建页面](/create-a-page)。
```

```md
让我们看看如何[创建页面](./create-a-page.mdx)。
```

**结果：** 让我们看看如何[创建页面](./create-a-page.mdx)。

## 图片

支持常规 Markdown 图片。

您可以使用绝对路径引用静态目录中的图片（`static/img/docusaurus.png`）：

```md
![Docusaurus logo](/img/docusaurus.png)
```

![Docusaurus logo](/img/docusaurus.png)

您也可以引用相对于当前文件的图片。这对于将图片与使用它们的 Markdown 文件放在一起特别有用：

```md
![Docusaurus logo](./img/docusaurus.png)
```

## 代码块

支持 Markdown 代码块，并带有语法高亮。

````md
```jsx title="src/components/HelloDocusaurus.js"
function HelloDocusaurus() {
  return <h1>Hello, Docusaurus!</h1>;
}
```
````

```jsx title="src/components/HelloDocusaurus.js"
function HelloDocusaurus() {
  return <h1>Hello, Docusaurus!</h1>;
}
```

## 警示框

Docusaurus 有特殊的语法来创建警示框和提示：

```md
:::tip[我的提示]

使用这个很棒的功能选项

:::

:::danger[注意]

这个操作是危险的

:::
```

:::tip[我的提示]

使用这个很棒的功能选项

:::

:::danger[注意]

这个操作是危险的

:::

## MDX 和 React 组件

[MDX](https://mdxjs.com/) 可以让您的文档更加 **交互式**，并允许在 Markdown 中使用 **任何 React 组件**：

```jsx
export const Highlight = ({children, color}) => (
  <span
    style={{
      backgroundColor: color,
      borderRadius: '20px',
      color: '#fff',
      padding: '10px',
      cursor: 'pointer',
    }}
    onClick={() => {
      alert(`您点击了颜色 ${color}，标签为 ${children}`)
    }}>
    {children}
  </span>
);

这是 <Highlight color="#25c2a0">Docusaurus 绿色</Highlight> !

这是 <Highlight color="#1877F2">Facebook 蓝色</Highlight> !
```
